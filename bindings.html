Bindings

Typed bindings for the JavaScript ecosystem

Hand-written, strongly typed F# and C# wrappers for the libraries and browser APIs you already use. Each package targets a specific upstream version, so the types match the JavaScript you actually ship.

Binding versions are refreshed from NuGet. Library versions show the latest stable release on npm.
