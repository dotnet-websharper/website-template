JavaScript libraries

Seamlessly use JavaScript libraries from F#

Charts, maps and grids drive Plotly, Leaflet and SlickGrid through WebSharper's typed JavaScript bindings — no hand-written interop. Forms shows the same idea with WebSharper's own typed form layer.

Samples

Learn by example

Every sample is a complete, open-source application built with WebSharper. The client-side ones compile to JavaScript and run entirely in the browser; the full-stack ones share F# types between a .NET server and the client.

Client-only samples

No server code — every one is live on GitHub Pages.
